# Security Policy

## API Keys

Never include an API key, signing key, password, backup file, or private
conversation in a GitHub issue, discussion, commit, screenshot, or log.

If an API key is exposed, revoke it through the provider immediately and
create a replacement.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting feature when it is available for
this repository. If it is unavailable, open a minimal public issue asking the
maintainer for a private contact channel without disclosing exploit details or
sensitive data.

## Supported Version

Security fixes are provided for the latest GitHub Release only.
