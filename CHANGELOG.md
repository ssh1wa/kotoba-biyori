# Changelog

## 1.7.0-beta.1 - 2026-07-26

First public beta release.

### Highlights

- Native furigana rendered above kanji instead of parenthetical readings.
- Local normalization for mixed kanji and okurigana segments.
- Chinese-Japanese translation, dictionary results, examples, grammar breakdown,
  and follow-up questions.
- Translation exercises with scoring, answer reveal, follow-up questions, and
  personalized review scheduling.
- Course-based and casual Mio roleplay with selectable learning level, local
  progress, multiple conversations, summaries, and shared memory.
- Calendar history, check-ins, vocabulary notebook, and JSON backup/import.
- Separate OpenAI-compatible and Gemini provider configuration per feature.
- Five color themes and user-editable learner profile.
