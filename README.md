# ことば日和

一个面向 Android 的日中双语学习应用。使用用户自己的 LLM API 完成翻译、词典查询、语法拆解、互译练习和日语角色对话，并使用原生布局把假名显示在汉字上方。

当前处于公开测试阶段。模型生成内容可能存在错误，重要知识点请结合可靠资料核对。

## 为什么做这个应用

普通 LLM 聊天客户端通常只能输出纯文本。即使模型知道日语读音，也往往只能写成“漢字（かんじ）”，无法像日语教材一样把假名真正排在汉字上方；长句还容易出现注音覆盖假名、读音错位和换行混乱。

ことば日和让模型返回结构化日文分段，再由应用使用原生界面渲染 Ruby 风格注音。

除了显示结果，应用还把翻译、语法拆解、练习纠错、课程进度和角色对话放进同一套本地学习记录中，适合把 LLM 当作长期日语学习工具，而不只是临时聊天窗口。

## 主要功能

- 日中互译与词典：自动识别方向；支持句子、单词、例句、词汇与语法说明。
- 汉字上方注音：日语假名使用 Ruby 风格布局显示，不使用括号注音。
- 互译练习：中译日、日译中、评分、参考答案、追问和个性化复习。
- 课程角色对话：按本地课程场景推进，结合生词、语法与学习进度生成对话。
- 随聊角色对话：多会话窗口、自动标题、共享记忆和可编辑的美绪长期设定。
- 学习记录：翻译、练习和课程对话均可按日期恢复完整内容。
- 日历打卡：完成练习或角色对话后自动记录。
- 生词本：支持查询、手动添加、AI 释义、删除和批量管理。
- 数据迁移：导出和导入学习记录、设置、打卡、聊天及课程进度；API Key 不进入备份。
- 双接口：支持 OpenAI Chat Completions 兼容接口和 Gemini `generateContent` 原生接口，各功能可独立选择提供商与模型。
- 多主题：内置日和朱、藍墨、青森、桜鼠和夜墨。

## API 与隐私

本应用没有自己的账号系统或中转服务器。用户需要在设置中填写自己的 API Key。

翻译、练习和角色对话请求会直接发送给用户选择的模型服务，包括用户输入、相关学习上下文和必要的对话记录。API Key 使用 Expo SecureStore 保存在设备上，不会写入源码或导出的备份文件。

使用前请阅读 [隐私说明](PRIVACY.md)。不要在 GitHub Issue、截图或日志中公开 API Key 和私人对话。

## 本地开发

需要 Node.js、JDK 17、Android SDK Platform 36 和 Android Build Tools 36。

```powershell
npm install
npm run typecheck
npm run prebuild:android
npm run apk
```

`android/`、`dist/`、本地工具链、签名密钥和签名密码均不会提交到仓库。
